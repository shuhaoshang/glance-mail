## Composition

`SceneCard` accepts the supplied item and controlled `selectedField` / `onSelectFact` props. A selection includes the field key, fact, and triggering element so the caller can show a SourcePanel and restore focus on close. Field keys distinguish values that share the same source fact.

Checklist progress stays inside the card and resets when the item ID changes. The optional completion callback reports progress without marking the item done. The completed note appears outside the card. The phone checklist story uses the reading-panel padding from the phone reference.
